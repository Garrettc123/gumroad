# Cover Art / Thumbnail Brief

Use this brief when designing (or commissioning) the cover image for your Gumroad
product listing.

---

## Gumroad Technical Requirements

| Requirement | Value |
|---|---|
| Minimum size | 1280 × 720 px |
| Aspect ratio | 16:9 (landscape) preferred |
| File format | PNG or JPEG |
| Maximum file size | 72 MB |

---

## Suggested Visual Direction

**Concept**: "Clean developer workbench" — convey a production-ready, professional
tool for technical founders, not a generic stock-photo marketplace template.

### Composition ideas

1. **Code + Commerce split** — left half shows a dark terminal/code editor with Ruby
   syntax highlighting; right half shows a clean product listing page on a browser
   mockup. Horizontal divider or subtle gradient between the two halves.

2. **Dashboard hero** — a browser mockup displaying the creator analytics dashboard
   (use a screenshot from the running local demo with sample data). Overlay a bold
   product title in white or near-white type.

3. **Stack badges** — a dark background with logos or badges for the core tech stack
   (Rails, React, MySQL, Stripe) arranged in a grid, with the product name as a
   large headline.

### Typography

- **Headline**: `Open-Source Creator E-Commerce Platform`
- **Subline**: `Self-Hosting Developer Kit`
- Font style: monospace or geometric sans-serif (e.g., JetBrains Mono, Inter, or DM Sans)

### Color palette

| Role | Suggested value |
|---|---|
| Background | `#111111` (near-black) or `#0f172a` (slate-900) |
| Accent | `#FF90E8` (Gumroad pink — use sparingly; do not imply affiliation) |
| Text | `#FFFFFF` or `#F8FAFC` |
| Secondary text | `#94A3B8` |

> Note: Using the Gumroad pink is common in open-source projects that reference the
> codebase, but avoid placing it so prominently that the image looks like official
> Gumroad branding. Add a small disclaimer line ("Not affiliated with Gumroad, Inc.")
> in the footer of the image if you use the pink.

### Things to avoid

- Generic stock photos of laptops or handshakes
- Screenshots containing real customer data or email addresses
- The Gumroad logo (trademark — not permitted without a license)
- Promises of revenue, income, or financial results
