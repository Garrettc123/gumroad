## FAQs

**Q: Do I need a Gumroad account to use this?**  
A: No. This is standalone source code you run on your own server. A Gumroad account is
only needed to buy this kit from the seller.

**Q: Do I need Stripe or PayPal?**  
A: The platform integrates with both. For local development you can use Stripe test-mode
keys. For a live store you will need accounts with Stripe and/or PayPal in a supported
country.

**Q: Can I white-label this as my own product?**  
A: Yes, under the MIT license. You must comply with the Gumroad trademark guidelines —
you may not use the "Gumroad" name or logo in your product name or hosted service.
See TRADEMARK_GUIDELINES.md included in the kit.

**Q: What hosting do I need?**  
A: A VPS or cloud instance with at least 2 GB RAM, plus managed MySQL, Redis, and object
storage (S3-compatible). The included production deployment docs outline one recommended
setup path.

**Q: Is this the official Gumroad software?**  
A: The code is derived from the publicly available open-source Gumroad repository
(https://github.com/antiwork/gumroad), which is MIT licensed. This kit is not affiliated
with or endorsed by Gumroad, Inc.

**Q: Can I get a refund?**  
A: See SUPPORT_POLICY.md included in the kit for the full refund terms.

**Q: What support is included?**  
A: See SUPPORT_POLICY.md for support tier details based on which pricing tier you purchased.
